# Claude Codeとのレビューと修正（2026年11月23日）

## 確認した範囲

共有保存先への転送、開いている画面の自動更新、独自ドメインの受入れをClaude Codeへ読み取り専用でレビュー依頼した。指摘をCodex側でコードと照合し、修正差分をさらに2回レビューした。Claude Codeは編集・テスト・公開を行っていない。修正と下記の実行確認はCodex側で実施した。

私的な会議記録、データベース、認証情報、個人用のCloudflare設定はレビュー入力に含めていない。レビュー原文はGit対象外の `.agent-reviews/` に保存している。

## 修正したこと

| 問題 | 修正後の動作 |
| --- | --- |
| 運営画面の背景更新が失敗すると、入力中の団体紹介が消える | 一時的な通信失敗では画面を置換せず、入力を残して復旧を待つ。権限失効時の表示消去とは分ける |
| 非同期で読み込む質問・回答フォームが、自動更新時に消える | 入力中の枠を保持して再取得し、最新の認証済み応答に同じフォームがある場合に入力・フォーカスを復元する |
| 質問の送信中に追記した文章も消える | 送信した本文と現在の本文が一致するときだけ入力を空にする |
| 自動的な認証失効で、未保存のマイページ変更が破棄される | 元のアカウント別に、このページのメモリへ保持する。同じ本人の再ログイン後、確認を経て復元・保存する。別アカウントには内容や復元操作を出さない |
| 保持した変更があると、別アカウントから破棄できない | 内容を表示せず、本人の確認でこの画面に保持した変更をすべて破棄できる |
| 画面切替中に受け取った更新が、次回も表示されない | 見送った描画を次の安定した取得で反映する |
| 停止後に遅れて接続確認が返ると、通知接続が開く | 停止と現在の画面・アカウントを接続直前にも確認する |
| 未ログイン接続で通知用の枠を使い切れる | 全体・未ログイン・アカウント・未ログインの直接接続元ごとに上限を設ける |
| 移行用IDの対応表がJavaScriptの継承プロパティまで参照する | 明示した対応表の項目だけを使う。入口では旧ブラウザーでも使える所有判定にする |
| 初回の質問取得失敗時に「読み込み中」が残る | 初期の読み込み表示を取り除いてエラーを示す |

Cloudflareでは別ゾーンのWorkerからの接続元IPが共通値になる。[公式のヘッダー説明](https://developers.cloudflare.com/fundamentals/reference/http-headers/#cf-connecting-ip-in-worker-subrequests)に沿い、その共通値とIP不明を訪問者別の制限に使わない。ログイン済みの接続を未ログイン接続元の枠に数えず、同じ学内回線の別アカウントを巻き込まない。

## 確認方法

- `node test-shared-data.cjs`：同じアカウント・残席競合・取消し・連絡板の権限・切替保護。
- `node test-live-auto-sync.cjs`：通知・2秒の代替取得・非表示からの復帰・認証失効。
- `node test-live-review-regressions.cjs`：画面切替中の取得、停止中の接続、アカウント別の保持、継承キー、通知接続上限。
- `node test-frontend-origin.cjs`：許可した公開先・Origin・共通保存先。
- `node test-account-ui.cjs`、`node test-community-questions.cjs`：既存の表示・保存・質問の公開範囲と権限。
- `node test-live-draft-preservation.cjs`：メモリ内DBと実際のブラウザーで、通信失敗からの復旧、質問・回答とフォーカスの保持、送信中の追記、認証失効、他アカウントへの非表示、本人確認後の復元、390px幅を確認する。本番は操作しない。
- `node test-cloudflare.cjs`：独立したローカルWrangler環境で認証・画像保存・セキュリティを確認する。
- ローカルworkerdの実WebSocket：対象アカウントだけへの通知、別アカウントへの非通知、異なるOriginの拒否、ログアウト失効を確認する。
- `node test-live-ws-limits.cjs`：ローカルWrangler専用。同じ回線からログイン済み32接続の後も未ログイン接続が可能で、1アカウント17本目は拒否されることを確認する。
- `node scripts/build-assets.cjs` と `git diff --check`。

ブラウザー用には依存関係の準備が必要。`TOBIYORI_TEST_OUTPUT_DIR` を設定すると確認画像を保存できる。`test-live-ws-limits.cjs` はローカルのURLだけを許可する。

## 現在の反映先と制限

今回の修正は `codex/shared-data` のローカル作業ツリーにある。GitHub送信・main統合・Cloudflare公開はしていない。公開中のアプリのソースは引き続き `4369389`。

新サイトは旧サイトを共通保存先にする方針を維持している。旧Workerが即時通知へ未対応の間は、新サイトの約2秒間隔の取得を使う。このレビューで新旧すべての画面への即時配信が実現したとは扱わない。

未保存変更の認証失効後の復元は、同じページを開いたまま使うもの。端末保存はせず、ページを閉じる・再読み込みすると失われるため、離脱時に確認を出す。ブラウザーの日本語IMEによる全環境の入力検証や、実際の利用者による効果検証は行っていない。
