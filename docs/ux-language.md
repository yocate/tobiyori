# 利用者向けの共通用語

画面では次の語を使う。内部のテーブル名やAPI名は変更しない。

| 画面で使う語 | 内部データ | 意味と表示上の決まり |
| --- | --- | --- |
| コミュニティ | `community` | 活動の主催者。地域団体、サークル、企業を含む。利用者向けの一覧・見出しでは「団体」と混用しない。 |
| 活動 | `activity` | 日時や参加条件を持つ参加機会。採用情報だけは「募集内容・応募条件」と表示する。 |
| よりみち発見 | `serendipity`、近隣検索 | 現在地または選んだ市の近くで開催中・近日開催の活動を探す入口。ログイン後は「いつもの興味の外からも探す」機能も使える。 |
| ラウンジ | `waiting_room` | 活動を検討する人の交流場所。入室は活動への申込みではない。 |
| 保存 | `saved_communities` | 本人だけが見返すための記録。通知は届かない。 |
| フォロー | `follows` | コミュニティの新しい活動について通知を受ける設定。参加や所属を意味しない。 |
| 申込み | `application` の `APPLIED` | 活動への参加希望を主催者に送った状態。参加はまだ確定していない。 |
| 参加予定 | `application` の `APPROVED` | 主催者が受け入れた状態。集合場所などを確認できる。 |
| 参加記録・参加完了 | `application` の `DONE` | 担当者が参加完了を記録した活動。ここから口コミを書ける。 |
| 口コミ | `review` | 参加完了した活動に本人が1件だけ投稿できる満足度と感想。表示名と内容を確認してから公開し、本人が編集・削除できる。他の利用者は通報できる。 |
| 活動への質問 | `activity_questions` | 特定の活動の内容や参加条件を主催者に尋ねる。回答した質問と回答を活動ページに公開する。 |
| コミュニティへの匿名質問 | `community_questions` | コミュニティの普段の活動や初参加・見学について尋ねる。回答前は質問した本人と担当者・運営者だけに表示し、回答後は質問と回答をコミュニティページに公開する。質問者の名前は表示しない。 |
| ご意見 | `feedback` | サイトの使いやすさや不具合を運営に伝える。コミュニティへの質問とは別の窓口。 |

利用者の基本導線は「活動を探す → 参加条件を見る → 申し込む → 承認後に参加」。よりみち発見とラウンジは申込み前に使える任意の導線。画面の最初には現在できる操作と判断に必要な条件を置き、詳細な確認記録・集計・説明は開閉できる領域に置く。

主な行き先は「ホーム」「さがす」「ラウンジ」「マイページ」。マイページは「参加」「保存・フォロー」「設定」にまとめる。通知はヘッダー、ガイドと相談はページ下部から開ける。
