# 質問から探す入口（ローカル試作）

目的：何から始めるか迷う利用者に、回答に応じた次の一歩を示す。
根拠：神保PMの2026-11-13の提案を、利用者が2026-11-14に実装依頼。

## 確認方法
利用者ホームの「質問に答えて、活動を探す」または `/#/start` を開く。
未ログインでも3問を利用できる。回答は画面内のメモリだけに保持し、更新時にリセットする。

1. やってみたいこと：新しい活動／大学・サークル／地域の仕事・企業
2. 最初の行動：1問目の回答に応じて、体験、紹介、質問、ラウンジ、インターン、採用情報などの選択肢を表示
3. 市町村：地域を限定しないことも可能

結果は公開カタログだけから抽出する。非公開、受付終了、変更確認中、所属者限定の募集は案内しない。質問・団体紹介・活動詳細・ラウンジへの遷移を変える。費用・年齢などすべての参加条件への適合は判定せず、詳細で確認してもらう。候補なしのときは、条件変更と既存一覧を案内する。

AI・外部API、回答の送信、プロフィール変更、自動申込みはない。データ取得エラーは候補なしと区別する。

## ローカル検証
確認用アプリを起動してから実行する。接続先の既定値は `http://127.0.0.1:4188`。異なる場合は `TOBIYORI_TEST_URL` で指定する。ブラウザーはWindowsではインストール済みEdgeを優先し、ほかの環境ではPlaywrightのChromiumを使う。`TOBIYORI_TEST_BROWSER` で実行ファイルを指定できる。スクリーンショットが必要な場合だけ `TOBIYORI_TEST_OUTPUT_DIR` に保存先を指定する。

`node test-guided-entry.cjs`：目的別分岐、地域、対象外の募集、候補なし、エスケープ、データを変更しないこと、ブラウザーで前後移動・やり直し・質問／ラウンジへのリンク・スマホ幅を確認。
ブラウザーの結果候補は通信を差し替えた検証データ。本番・ローカルDBへの団体・募集の追加はしない。
既存の継続参加導線テストと公開用ビルドも確認。2026年11月18日の利用者指示により、改修用ブランチをGitHubへ送る。mainへの統合と本番公開は別途行う。

## 二人で検討すること
- 最初の選択肢と言葉は、利用する学生の目的に合っているか。
- 3問は負担にならないか。地域の質問が必要か。
- 案内した先で、次に何を押すか分かるか。
- 実データで候補が少ない場合、団体紹介へ進む案内が十分か。
